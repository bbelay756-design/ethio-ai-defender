Windows Portable Executable (PE) Structural Map

Understand how a 32-bit/64-bit Windows binary is organized on disk and how the Windows OS PE loader maps relative virtual addresses (RVA) into process memory.

1. IMAGE_DOS_HEADER (64 Bytes) Offset 0x0000
Begins with magic signature 'MZ' (0x5A4D). Offset 0x3C (e_lfanew) points to the start of the PE NT Headers.
2. MS-DOS 2.0 Stub Program Variable Size (~64 Bytes)
Legacy 16-bit real-mode program printing "This program cannot be run in DOS mode."
3. IMAGE_NT_HEADERS (Signature + COFF Header + Optional Header) Offset = e_lfanew
Contains 'PE\0\0' signature, CPU architecture (x86/x64), number of sections, compile timestamp, AddressOfEntryPoint, ImageBase, and DataDirectory (Imports, Exports, Resources, Relocations).
4. IMAGE_SECTION_HEADER Table (40 Bytes per Section) Directly follows Optional Header
Array of 40-byte descriptors defining memory section names, VirtualAddress (RVA), VirtualSize, SizeOfRawData, and Memory Access Characteristics (Read, Write, Execute).
.text Section
Executable CPU machine code (Execute + Read).
.rdata / .idata
Read-only constants, string literals, and IAT descriptors.
.data Section
Read/Write global variables and memory buffers.
.rsrc Section
Application icons, dialog templates, version manifests.
